## Bug 修复：小组件修改经量后进入 App 不同步（1.33.1+104）

**现象**：App 在后台，用户在桌面小组件上把经量从"少"改为"多"，再点小组件进入 App，App 仍显示"少"；反向（App 改 → 小组件同步）正常。

**根因**：`app.dart` 的 `_MyAppState` 中三条小组件→App 同步路径（`dataChanged` 回调、启动检查、`resumed` 恢复检查）都用 `context.read<PeriodProvider>()`，但该 context 位于 `MultiProvider` **上方**（Provider 在其 `build()` 内部创建），查找必然抛 `ProviderNotFoundException` 且被静默吞掉。更糟的是 `dataChanged` 回调里 `clearDataDirty()` 在抛异常之前执行，把 dirty 标记清掉了，连"恢复前台兜底检查"也被破坏。

**修复**（仅改 `lib/app.dart`）：
- Provider 改为在 `initState` 中创建（`late final` 字段，`PeriodProvider()..loadRecords()` / `SettingsProvider()..ensureLoaded()`）
- `MultiProvider` 用 `ChangeNotifierProvider<T>.value` 注入同一实例
- 三条同步路径直接引用 `_periodProvider` 字段，不再走 context 查找
- `dispose()` 中手动 dispose 两个 Provider（`.value` 注入不会自动释放）

**教训（重要）**：在创建 Provider 的 State 生命周期回调里不能用 `context.read`；Provider 查找只向上、不向下。要么把 Provider 提到上方，要么直接持有实例。

**附带**：补齐两个测试 mock（`home_screen_test.dart` / `add_record_calendar_test.dart`）缺失的 `refreshConnection` 实现（今早加接口时漏的，导致 analyze 报 error、测试无法编译）。

**验证**：analyze 0 error（剩 2 条存量 info）；flutter test 75/75 通过；release APK 构建成功（58.7MB）。

## Bug 修复：记录页历史记录跨机型排版不一致（1.34.1+110）

**现象**：记录页"历史记录"列表在不同手机上排版不齐。

**根因**（`_buildRecordRow` 三处跨机型隐患）：
1. 日期徽标 46×46 固定容器内文字跟随系统字体缩放，大字体（各 ROM 默认不同）下溢出错位；
2. 日期区间文本无 maxLines，窄屏/大字体下换行导致行高参差；
3. 心情标签裸 `TextStyle(fontSize: 14)` 无 height，厂商字体（MiSans/HarmonyOS Sans 等）度量不同 → 行高不一致。

**修复**（仅改 `lib/screens/record_screen.dart`）：
- 历史列表包 `MediaQuery.withClampedTextScaling(maxScaleFactor: 1.3)` 钳制文本缩放上限；
- 日期徽标两处 Text 加 `textScaler: TextScaler.noScaling`（固定字号保证徽标视觉一致）；
- rangeText 加 `maxLines: 1 + ellipsis`；
- 心情 Text 改用 `AppTheme.bodyMedium`（带 height 1.5）。

**验证**：analyze 0 issue，136/136 测试通过。版本 1.34.0+109 → 1.34.1+110。

## 跨机型 UI 一致性：内置 MiSans + 全局文本缩放钳制（1.35.0+111）

**目标**：所有页面 UI/字体样式在不同手机、不同分辨率下表现一致。

**实施**：
1. 下载官方 MiSans.zip（227MB，hyperos.mi.com，断点续传循环下载；npm misans 包只有切片 woff2 不可用），取 Regular/Medium/Semibold/Bold 4 字重；
2. fonttools 子集化（GB2312 全部 6763 汉字 + ASCII + Latin-1 + CJK/全角标点，共 7803 码点，--no-hinting），每字重 ~1.7MB，共 6.6MB → assets/fonts/；
3. pubspec.yaml 声明 family MiSans（weight 400/500/600/700）；
4. AppTheme 新增 `static const String fontFamily = 'MiSans'`，light/dark ThemeData 均设 fontFamily（widget 裸 TextStyle 继承 DefaultTextStyle 自动生效）；
5. **TextPainter 不继承主题字体**：4 个图表文件（cycle_chart / period_length_chart / health_score_trend_chart / year_heatmap）共 8 处 TextPainter 样式显式加 `fontFamily: AppTheme.fontFamily`；
6. app.dart MaterialApp.builder 全局 `MediaQuery.withClampedTextScaling(min: 1.0, max: 1.3)` 钳制系统字体缩放（此前 record_screen 局部钳制已移除，避免重复）。

**验证**：analyze 0 issue；136/136 测试通过；debug APK 构建成功且 4 个字体文件确认在 APK assets 内。版本 1.34.1+110 → 1.35.0+111。
